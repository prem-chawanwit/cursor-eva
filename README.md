# cursor-eva

โปรเจกต์สำหรับทดลองและประเมินการใช้งาน **Cursor** (Cursor Evaluation)

---

## 📌 เกี่ยวกับโปรเจกต์นี้

Repository นี้ใช้สำหรับ

- ทดลองฟีเจอร์ต่าง ๆ ของ Cursor เช่น Agent, Cloud Agent และการแก้ไขโค้ดอัตโนมัติ
- เก็บตัวอย่างงานที่ให้ AI ช่วยทำ เพื่อนำมาประเมินผลลัพธ์
- ฝึกใช้งาน workflow แบบ AI-assisted (สั่งงาน → ตรวจสอบ → ปรับปรุง)

## 🚀 เริ่มต้นใช้งาน

1. Clone โปรเจกต์ลงเครื่อง

```bash
git clone https://github.com/prem-chawanwit/cursor-eva.git
cd cursor-eva
```

2. เปิดโฟลเดอร์ด้วย Cursor แล้วเริ่มทดลองสั่งงาน Agent ได้เลย
