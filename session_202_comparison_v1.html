01 / Lab findings

เทียบ 3 เจ้า จากการใช้งานจริงของทีม

สรุปจากการลองใช้จริงใน lab ไม่ใช่จาก spec sheet — รอบนี้ใช้ Cursor เป็นตัวหลัก

Cursor — เครื่องมือหลักที่ทดลอง

ทำได้ดี
  • Automation & Workflow: ทำ pipeline automation ของ development task ได้ง่าย ดูสถานะและจัดการ sub-agent ระหว่างสั่งงานได้ดี
  • Plan Mode ให้ workflow ที่เข้าใจง่าย, Ask Mode ถามกลับเมื่อ agent ไม่แน่ใจ และมี built-in doc ให้ agent อ้างอิง
  • Multi-model review: สั่งหลาย model รีวิวโค้ดพร้อมกันแล้วทำ majority vote ได้
  • Team & Enterprise: Team Rules บังคับ coding standard ทั้งทีม, ตั้ง spend alert/limit ง่าย, dashboard analytics ครบ, เห็น usage รายคนละเอียด
  • Audit & Traceability: ดู Agent Line of Code ได้ใน metric และ audit log บอกว่าใครทำอะไร เช่น เพิ่ม MCP
  • เสถียร: native desktop app และการแจ้งเตือนแบบ native ใช้ได้ดี พร้อม Cloud Sandbox ที่ควบคุมผ่าน UI ได้
ข้อจำกัดที่เจอ
  • ไม่มี mode Co-work — ผูกกับ repository เน้น code เป็นหลัก เหมาะกับ Developer & SE มากกว่า end user
  • Microsoft extension ไม่ครบเท่า VS Code: ขาด Azure Functions (deploy Function App / list resource) ส่วน C# Dev Kit มีแต่ไม่ใช่ official และบางครั้ง conflict กับ extension อื่น
  • Cloud Agent ยังไม่ native support Azure DevOps repository (กำลัง explore เพิ่มเติม)
  • ต้องใช้เวลา research + config เพิ่ม ถ้าจะใช้ Cloud Agents เต็มรูปแบบ

GitHub Copilot — ข้อสังเกตจากการใช้

  • Crash บ่อยเมื่อเจอ task ขนาดใหญ่
  • จุดแข็งคือความเข้ากับ VS Code / GitHub / Azure ดูรายละเอียดในตาราง 02

Claude — ข้อสังเกตจากการใช้

  • Co-work เกิด crash ในบางกรณี เช่น งานที่ไล่ step 1, 2, 3 ต่อเนื่อง
  • เด่นเรื่องแชร์ context ระหว่างทีม technical กับ business — เป็นคนละกลุ่มกับ IDE assistant

Take aways

  1. 1Cursor กับ Copilot สูสีมาก (48 vs 46 จาก 55 ดาว) — สเกลดาวสะท้อนความลึกของฟีเจอร์ ทำให้ Cursor ขยับขึ้นนำเล็กน้อยจากด้าน agent/sandbox/automation ขณะที่ Copilot ยังเด่นสุดเรื่อง ecosystem และความง่ายสำหรับ dev ใหม่
  2. 2Claude เป็นอีกกลุ่ม (Co-work) — ใช้เสริมงานข้ามทีม ไม่ใช่ตัวแทน IDE assistant
  3. 3Privacy & IP ต้องปิดก่อน rollout: ทุกเจ้าทำ no-training/ZDR ได้ แต่ indemnification ต่างกัน — Copilot ผูกเงื่อนไข filter/tier, Cursor ต้องต่อรองในสัญญา, Claude มีแบบจำกัด cap[16][17][18]
  4. 4Hybrid 3 เจ้ามีต้นทุนแฝง (สัญญา + security review หลายรอบ) — เริ่ม 2 เจ้าพร้อม central policy และโครงสร้างราคายังไม่ได้รีวิว ต้องทำ TCO แยกอีกฉบับ
